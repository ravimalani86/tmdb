App JSON Admin

Create and edit per-app JSON. Flutter fetches with POST /app-config. 

        curl -sS -X POST "http://localhost/tmdb/api/app-config" \
          -H "Content-Type: application/json" \
          -H "X-API-Key: YOUR_KEY" \
          -d '{"app_id":"movflik"}'
